## Global Constraints (geçerli)

- **Üretim dondurması:** kullanıcı açıkça `CANLIYA UYGULA` demeden hiçbir migration, DDL, DML,
  GRANT/REVOKE, Edge Function deploy'u ya da `main`'e push yok. Push = GitHub Pages yayını.
- **Parola ve sır:** DB parolası istenmez; salt-okuma sorgularını kullanıcı
  `docs/kurulum/sql-uygula.ps1 -SaltOkuma` ile çalıştırır. Sır dosyaya/geçmişe yazılmaz.
- **Operasyon günü A1'de yazılmaz** (tasarım 3.3). Saat kesimi (06:00, `gun_sonu_saati`) hiçbir
  yerde kullanılmaz.
- **Stok tarih düzeltmesi korunur** (tasarım 3.5.1): her stok yazma yolu `guncelleme_tarihi = now()`
  yazar; ön koşul mevcut gövdede tarih düzeltmesini arar; geri alma onu korur; ekran tarihi
  sunucudan okur.
- **Test tabanı üretimi temsil eder:** 2026-09-18 sonrası üretim şema dökümü; stok RPC gövdeleri
  md5 ile doğrulanır (`scripts/stok-rpc-govde.mjs` deseni). Elle yazılmış RPC kopyası yasak.
- **Kanıt gerçek dosyayla:** sıra, geri alma ve Edge testleri plan metninden alıntıyı değil
  `docs/kurulum/` altındaki gerçek dosyaları çalıştırır.
- **Negatif kontrol zorunlu:** kilit, rezerve koruması, tekillik, tarih düzeltmesi — koruma
  kaldırıldığında test **düşmelidir**.
- **Migration standardı:** `MIGRATION-GUVENLIK-STANDARDI.md` + `SABLON-yeni-migration.sql`;
  `node scripts/migration-guvenlik-kontrol.mjs` 0 HATA; denetleyici öz-testi 15/15 (LF+CRLF).
- **Edge kuralı** (tasarım 5.3): kodu ya da davranışı değişen Edge Function uçtan uca testi
  geçmeden yayına girmez; test açığını belgeye yazmak yayına hazır yapmaz.
- **Hata metinleri** `KOD: açıklama` biçiminde (tasarım bölüm 9).
- Commit yapılır; push yalnız `CANLIYA UYGULA` ile.
